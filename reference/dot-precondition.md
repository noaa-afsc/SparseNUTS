# Update algorithm for mass matrix.

Update algorithm for mass matrix.

## Usage

``` r
.precondition(metric, fn, gr, inputs, y.cur)
```

## Arguments

- metric:

  The metric to use

- fn:

  The current fn function.

- gr:

  The current gr function

- inputs:

  A list of inputs

- y.cur:

  The current parameter vector in unrotated (Y) space.
